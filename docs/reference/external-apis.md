# 외부 API·데이터원

발급해 둔 키와 지금 설계에서 쓰는지 여부를 한 표로 정리한다. **키 값은** `.env`**에만 두고, 여기엔 변수명만 적는다.**

## 발급한 API


| 서비스                     | 키(.env)                                                           | 받는 것                                  | 현 설계 사용 |
| ----------------------- | ----------------------------------------------------------------- | ------------------------------------- | ------- |
| **KIS Developers** (실전) | `KIS_APP_KEY`·`KIS_APP_SECRET`·`KIS_ACCOUNT_NO`                   | 국내 시세·일봉·수급(최근 30거래일)·공매도·종목마스터·계좌·주문 | **사용**  |
| **KIS Developers** (모의) | `KIS_PAPER_APP_KEY`·`KIS_PAPER_APP_SECRET`·`KIS_PAPER_ACCOUNT_NO` | 〃 (모의 도메인도 시세 4종 제공)                  | **사용**  |
| **DART**                | `DART_API_KEY`                                                    | 기업행위 정형 공시(무상증자·감자·유상증자의 기준일·배정비율)    | **사용**  |
| **FRED**                | `FRED_API_KEY`                                                    | 美10Y 금리·한은 기준금리                       | **미사용** |
| **healthchecks.io**     | `HEALTHCHECK_URL`                                                 | 데드맨 스위치(사이클 정상 종료 ping)               | **사용**  |
| **Discord 웹훅**          | `DISCORD_WEBHOOK_URL`                                             | 운영 알림                                 | **사용**  |
| **Anthropic (Claude)**  | `ANTHROPIC_API_KEY`                                               | LLM 호출                                | **미사용** |
| **네이버 검색**              | `NAVER_CLIENT_ID`·`NAVER_CLIENT_SECRET`                           | 뉴스 헤드라인                               | **미사용** |
| **KRX**                 | `KRX_API_KEY`                                                     | (수급·공매도 미제공)                          | **미사용** |




## 키 없이 쓰는 데이터원


| 출처                     | 받는 것                                     | 현 설계 사용 |
| ---------------------- | ---------------------------------------- | ------- |
| **네이버 금융** (HTML 스크래핑) | 과거 수급(외국인·기관 8년+)·상폐 종목 과거 시세 - 백테스트에 사용 | **미사용** |
| **yfinance**           | 코스피·코스닥 지수, 해외 지수·환율                     | **사용**  |




## 실측으로 확인한 제약

- **KIS 토큰**: 24시간 만료, **발급은 1분당 1회**(`EGW00133`) → 파일 캐싱 재사용
- **KIS 수급**: `inquire-investor`는 **최근 30거래일만** 제공 → 과거 수급은 네이버 금융. 반면 공매도는 과거 구간도 조회 가능.
- **KIS 일봉**: 한 호출 최대 ~100건 → 장기 구간은 페이지네이션. 12년치까지 수신 확인.
- **KIS 모의 미지원**: 스톱지정가(`ORD_DVSN=22`), IOC, 실현·기간손익 조회. 손절 메커니즘은 소액 실거래에서 검증
- **KIS 해외 IP 차단**: 한국 IP 상시 호스트가 전제
- **네이버 금융**: 공식 API가 아니라 공개 HTML 파싱이다. 인코딩 euc-kr, 종목은 단축코드 6자리. 페이지당 소량이라 종목당 수십~100요청 → 요청 간 지연 + 1회 수집 후 캐싱이 필수다. 구조가 바뀌면 깨지므로 파서를 격리하고 실패를 알린다.
- **yfinance**: 과거 값이 조용히 사후 수정된다 → 수집 시점 스냅샷을 동결
