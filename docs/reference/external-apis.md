# 외부 API·데이터원

발급해 둔 키와 지금 설계에서 쓰는지 여부를 한 표로 정리한다. **키 값은** `.env`**에만 두고, 여기엔 변수명만 적는다.**

## 발급한 API


| 서비스                     | 키(.env)                                                           | 받는 것                                  | 현 설계 사용 |
| ----------------------- | ----------------------------------------------------------------- | ------------------------------------- | ------- |
| **KIS Developers** (실전) | `KIS_APP_KEY`·`KIS_APP_SECRET`·`KIS_ACCOUNT_NO`                   | 국내 시세·일봉·수급(최근 30거래일)·공매도·종목마스터·계좌·주문 | **사용**  |
| **KIS Developers** (모의) | `KIS_PAPER_APP_KEY`·`KIS_PAPER_APP_SECRET`·`KIS_PAPER_ACCOUNT_NO` | 〃 (모의 도메인도 시세 4종 제공)                  | **사용**  |
| **DART**                | `DART_API_KEY`                                                    | 기업행위 정형 공시(무상증자·감자·유상증자의 기준일·배정비율)    | **사용**  |
| **FRED**                | `FRED_API_KEY`                                                    | 美10Y 금리·한은 기준금리                       | **미사용** |

## 키 없이 쓰는 데이터원


| 출처                     | 받는 것                                     | 현 설계 사용 |
| ---------------------- | ---------------------------------------- | ------- |
| **네이버 금융** (HTML 스크래핑) | 과거 수급(외국인·기관 8년+)·상폐 종목 과거 시세 - 백테스트에 사용 | **미사용** |

## 실측으로 확인한 제약

- **KIS 토큰**: 24시간 만료, **발급은 1분당 1회**(`EGW00133`) → 파일 캐싱 재사용
- **KIS 수급**: `inquire-investor`는 **최근 30거래일만** 제공 → 과거 수급은 네이버 금융. 반면 공매도는 과거 구간도 조회 가능.
- **KIS 일봉**: 한 호출 최대 ~100건 → 장기 구간은 페이지네이션. 12년치까지 수신 확인.
- **KIS 모의 미지원**: 스톱지정가(`ORD_DVSN=22`), IOC, 실현·기간손익 조회. 손절 메커니즘은 소액 실거래에서 검증
- **KIS 해외 IP 차단**: 한국 IP 상시 호스트가 전제
- **yfinance 컬럼 대소문자**: 지수 응답은 `Close`·`High`처럼 첫 글자가 대문자다(단일 심볼도 `(필드, 심볼)` MultiIndex). 소문자로 `rename`을 걸면 조용히 실패한다 — 받은 뒤 소문자로 정규화할 것(2026-09-07 실측)
- **KIS 장 시작 전 일봉**: 개장 전에 당일을 조회하면 전일 종가로 채운 **거래량 0짜리 미확정 봉**이 온다. 그대로 적재하면 고가=저가라 ATR이 0이 된다 — `volume > 0`으로 확정 봉만 받을 것(2026-09-07 실측)

### KIS 주문 정정취소 (`TTTC0013U`)

트레일링·본전 상향으로 손절선이 올라가면 KIS에 걸린 예약도 함께 고쳐야 한다(10-ops 10.13).
공식 샘플([open-trading-api](https://github.com/koreainvestment/open-trading-api))에서 확인한 규격:

| 항목 | 값 |
| - | - |
| 경로 | `/uapi/domestic-stock/v1/trading/order-rvsecncl` |
| TR ID | 실전 `TTTC0013U` · 모의 `VTTC0013U` |

| Body 필드 | 뜻 |
| - | - |
| `KRX_FWDG_ORD_ORGNO` | 한국거래소전송주문조직번호 — **원주문 응답에서 받아 두어야 한다** |
| `ORGN_ODNO` | 원주문번호(`ODNO`) |
| `ORD_DVSN` | 주문구분(스톱 유지 시 `22`) |
| `RVSE_CNCL_DVSN_CD` | `01`=정정, `02`=취소 |
| `ORD_QTY` · `ORD_UNPR` | 수량 · 단가 |
| `QTY_ALL_ORD_YN` | `Y`=잔량 전부 |
| `EXCG_ID_DVSN_CD` | `KRX` / `NXT` / `SOR` |
| `CNDT_PRIC` | 조건가격 — 스톱의 **새 발동가**를 여기 넣는다 |

- **이미 체결된 주문은 정정·취소되지 않는다.** 실패를 정상 경로로 다뤄야 한다.
- 정정하면 **새 주문번호가 발급**되므로, 다음 정정을 위해 갈아 끼워 저장한다.
- 공식 문서는 호출 전 정정취소가능주문조회(`inquire-psbl-rvsecncl`)로 가능수량 확인을 권한다.
- **네이버 금융**: 공식 API가 아니라 공개 HTML 파싱이다. 인코딩 euc-kr, 종목은 단축코드 6자리. 페이지당 소량이라 종목당 수십~100요청 → 요청 간 지연 + 1회 수집 후 캐싱이 필수다. 구조가 바뀌면 깨지므로 파서를 격리하고 실패를 알린다.
- **yfinance**: 과거 값이 조용히 사후 수정된다 → 수집 시점 스냅샷을 동결
